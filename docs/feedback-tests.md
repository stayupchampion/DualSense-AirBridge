# 独立反馈测试

入口：主窗口“反馈测试”。不需要进入游戏关卡；请先正常退出正在使用这只手柄的游戏。

## 蓝牙测试

1. 拔掉 USB 数据线，按 PS 键通过普通蓝牙连接。
2. 在主窗口启用蓝牙桥接，等待“已连接”。
3. 打开“反馈测试”，刷新目标，选择“虚拟 USB（USB/IP）”。
4. 分别点三个测试按钮：
   - 左右精细触觉：约 4 秒，左侧、右侧、双侧。使用四声道音频中的第 3/4 通道，扬声器通道保持静音，不是普通双马达震动命令。
   - 右扳机阻力：最多 5 秒，轻按 R2 感受阻力；不要用力掰动。
   - 手柄扬声器：两声低音量提示，仅写入这只手柄的音频端点，不切换 Windows 默认耳机。
5. 每项自动停止。“立即停止”、关闭测试面板或停止桥接，都会先取消测试并等待清理。

## USB 对照

停止桥接并确认恢复，插入 USB 数据线，刷新测试目标，选择“物理 USB 原生”，重复同一测试。
两种模式使用完全相同的测试信号。记录左右触觉顺序、阻力位置和力度、扬声器是否有声，再比较明显延迟和断续。

## 证据边界与清理

- 面板的“信号已发送”不是感官验收。实际反馈需要使用者确认；独立测试通过也不证明某一游戏会调用这些功能。
- 不修改耳机默认端点、系统音量或手柄固件。音频测试只选择与目标手柄同一 USB composite root 的端点，找不到时失败，不改用默认扬声器。
- 结束扳机测试会发送关闭效果报告；结束音频测试会 Stop/Reset 本次音频流。扬声器测试结束会把测试设置的手柄扬声器音量置零，不能声称恢复某个正在运行游戏先前的音量/路由，因此要求先退出游戏。
- 运行记录在程序 .local/feedback-tests/，包含目标、模式、格式、发送帧数、结束/取消/错误状态；不自动把主观感受记为通过。
- 当前软件检查 57 项通过，面板已渲染检查。首次硬件测试在发送测试信号前发生蓝牙掉线：当时 PBZ.exe 和 Steam 仍在后台；持续摇杆也复现。两者退出后的隔离实测已完成三种信号发送与取消清理；主观感受、USB 对照和游戏效果仍待确认。见文末记录。
