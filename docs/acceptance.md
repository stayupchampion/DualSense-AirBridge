## 退出与异常

- 正常停止、正常关闭窗口：后端退出；本次虚拟端口不再存在；本次隐藏和应用登记撤销；默认音频维持原设备。
- 蓝牙手柄断开：工具结束会话并恢复，不无限后台接管。
- 仅主窗口异常退出：管理器完成清理。
- 管理器被强杀：后端被 Job Object 结束；重新打开执行持久化恢复。该场景不能宣称立即完全无残留。
- 重启电脑且不打开工具：无 vDS 自动服务或本工具开机项；原生 USB/蓝牙手柄可用。

如游戏 USB 原生基线就没有某项功能，不据此声称桥接可补出该功能。游戏适配结论须附游戏版本、场景与复现步骤。
