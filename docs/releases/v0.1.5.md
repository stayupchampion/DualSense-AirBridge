## 简体中文

**DualSense AirBridge v0.1.5 正式 Release，适用于 Windows x64 与普通 DualSense。**

此版本包含已验证的 `0.1.5-dev.4` 功能代码；正式发布调整版本标识、文档和发布流程，运行时功能保持一致。

### 更新内容

- 重新整理主窗口、检查与恢复页面、反馈测试和延迟对比界面。
- 增加手柄电量、默认音频设备和音量显示；手柄扬声器默认静音，可在工具中开启，精细触觉和扳机反馈保留。
- 分离虚拟扬声器／麦克风的 USB 音量控制；将系统音频查询和默认设备保护放入有时限的独立进程，避免查询阻塞停止流程。
- 加固正常停止、直接关闭窗口和异常恢复。只撤销本次桥接拥有的变更，保留用户后续调整的外部输出、音量和其他软件配置。
- 修复退出后残留黄色灯光：释放桥接灯效，再请求手柄自身恢复原生蓝牙灯光。
- 修正断连后的状态显示、后端重复接管风险，以及命令超时、未完成握手和 Windows 状态文件读写竞争。保留既有触觉缓冲参数。

### 下载和使用

下载 **`DualSense-AirBridge-v0.1.5-win-x64.zip`**，完整解压后运行 `DualSenseBridge.exe`。随包提供 .NET 9 运行时；驱动不包含在压缩包内，也不会自动安装。已有可用环境无需为本次版本更新更换驱动。

首次使用需安装官方 [usbip-win2 0.9.8.1](https://github.com/vadimgrn/usbip-win2/releases/tag/v.0.9.8.1) 和 [HidHide 1.5.230.0](https://github.com/nefarius/HidHide/releases/tag/v1.5.230.0)。默认不开机自启。先启用桥接再启动游戏，切换或更新版本前先退出游戏并正常停止桥接。不要覆盖正在运行的程序目录。

附件 `SHA256SUMS.txt` 用于校验下载，`build-manifest.json` 记录源码提交及程序摘要。GitHub 自动生成的 Source code ZIP/TAR 是源码，不是可运行包。使用步骤和第三方许可见[中文 README](https://github.com/stayupchampion/DualSense-AirBridge/blob/v0.1.5/README.md)。

### 验证范围

候选版通过 238 项 C# 检查、原生后端检查、4 项补丁兼容性检查，以及音频子进程和恢复故障测试。正式包由 GitHub Actions 从标签源码重新构建并重复软件检查；CI 不连接实体设备。

本机实测覆盖点击停止与直接关闭工具：用户确认精细触觉、R2 阻力、原生蓝灯、Bose 播放和实际音量调节正常。关闭后约 95 秒的 19 次只读采样全部读到原生蓝牙输入，未发现活动桥接残留或恢复警告。

自然待机／唤醒及原生 USB 回退尚未针对本次候选版复测；不能将上述结果外推为所有蓝牙适配器和游戏的保证，也未认定此前 Bose 故障的根因已彻底解决。麦克风、3.5mm 音频、其他手柄共存及任意先前自定义灯效未完成全面验收。仅普通 DualSense 可作为桥接目标；不承诺完整无线化所有 USB 功能或零延迟。恢复范围与固件状态限制见[详细说明](https://github.com/stayupchampion/DualSense-AirBridge/blob/v0.1.5/docs/controller-state-recovery.md)。

桥接后端基于 [vDS](https://github.com/hurryman2212/vds)，依赖 usbip-win2、HidHide 和 Opus；Rea、DS5Dongle 等研究工具及协议参考的作用、固定版本与许可列于 README。自有代码采用 MIT，第三方许可随包保留。

## English

**DualSense AirBridge v0.1.5 is a regular Release for Windows x64 and standard DualSense controllers.**

This release promotes the tested `0.1.5-dev.4` functionality. Only version metadata, documentation and release automation change during promotion.

- Refreshed UI, battery display, default-audio/volume display, and controller-speaker mute enabled by default.
- Independent virtual speaker/microphone volume controls and bounded audio helper processes.
- Stronger stop, window-close and recovery handling; only tool-owned system changes are reverted, preserving subsequent user choices and unrelated software settings.
- Native Bluetooth lighting handoff fixes the yellow light remaining after shutdown.
- Improved disconnect status, single-session ownership, command deadlines, handshake cancellation and atomic state-file writes. Existing haptic buffering remains unchanged.

Download and fully extract **`DualSense-AirBridge-v0.1.5-win-x64.zip`**, then run `DualSenseBridge.exe`. The .NET 9 runtime is bundled. Official usbip-win2 0.9.8.1 and HidHide 1.5.230.0 drivers are separate; an already working installation does not need a driver change for this release. There is no automatic startup. Exit the game and stop bridging before switching versions; do not overwrite a running application directory.

The candidate passed 238 C# checks, native backend checks, 4 patch checks and synthetic audio/process/recovery fault tests. The tagged release is rebuilt and software-tested in GitHub Actions. Hardware acceptance was performed locally on the candidate, not by CI: normal stop and direct window close restored the native blue light; haptics, R2, Bose playback and audible volume adjustment passed. Nineteen read-only observations over approximately 95 seconds found readable native input and no recovery warnings.

Natural standby/wake and native USB fallback still need a new regression pass. The historic Bose fault is not claimed universally resolved. Broader hardware/game compatibility, microphone, 3.5mm audio, concurrent controllers and arbitrary pre-existing custom lighting remain outside full acceptance. The tool does not promise every USB capability over Bluetooth or zero latency.

Checksums and a source/binary manifest accompany the executable ZIP. Automatic source archives are not runnable packages. See the [English README](https://github.com/stayupchampion/DualSense-AirBridge/blob/v0.1.5/README.en.md) for instructions, scope, upstream credits and dependencies. Project code is MIT; bundled third-party notices remain intact.
