## 简体中文

**DualSense AirBridge 首个公开预览版，适用于 Windows x64 和普通 DualSense。**

手柄照常通过 Windows 蓝牙连接，工具向兼容游戏提供虚拟 USB DualSense，转发输入、左右精细触觉与自适应扳机。首个重点验证游戏为《影之刃：零》Steam 版。

- 已包含触觉缓冲与 USB/IP 调度优化，以及有界后台诊断队列，减少收发路径等待。
- 内置反馈测试与 USB / 蓝牙桥接对比模块。
- 默认不开机自启；正常退出撤销本次隐藏规则并清理本次虚拟设备。切换模式前请先退出游戏。
- 包含中文默认 README、英文 README、新图标、MIT 许可和第三方许可通知。

### 下载和运行

下载 `DualSense-AirBridge-v0.1.4-win-x64.zip`，完整解压后运行 `DualSenseBridge.exe`。包含 .NET 9 运行时；驱动需另从官方来源安装：

- [usbip-win2 0.9.8.1 x64](https://github.com/vadimgrn/usbip-win2/releases/tag/v.0.9.8.1)
- [HidHide 1.5.230.0 x64](https://github.com/nefarius/HidHide/releases/tag/v1.5.230.0)

安装时按提示重启。先连接普通 DualSense 蓝牙、启用桥接，再启动游戏。需要时只对该游戏禁用 Steam 输入。使用步骤、恢复说明与依赖关系见[中文 README](https://github.com/stayupchampion/DualSense-AirBridge/blob/v0.1.4/README.md)。

`SHA256SUMS.txt` 提供下载校验，`build-manifest.json` 记录源码提交和程序摘要。GitHub 自动提供的 Source code ZIP/TAR 是源码，不是可运行包。程序未使用商业代码签名证书签名。

### 验证和限制

发布流程重新构建源码并运行 121 项 C# 检查、C++ 运行时/诊断检查、3 项补丁检查和无驱动后端生命周期测试。此前单机实测确认左右触觉、R2 阻力、取消归零、正常退出恢复与独立 Bose 蓝牙音频共存；CI 不进行实机验收。

用户体感已接近 USB，但没有完成高速摄影或仪器测量，不能承诺等延迟。手柄扬声器实测无声，麦克风与 3.5mm 音频未验收。仅普通 DualSense 已允许桥接，不支持 Edge、DS4、Xbox；其他手柄并发和广泛游戏兼容尚未验证。

核心桥接后端基于 [vDS](https://github.com/hurryman2212/vds)，结合 usbip-win2、HidHide 与 Opus。完整来源、固定提交和参考项目见 README；自有代码采用 MIT，第三方许可保留。

## English

**First public preview of DualSense AirBridge for Windows x64 and standard DualSense controllers.**

Pair the controller through Windows Bluetooth. The tool exposes a virtual USB DualSense to compatible games, forwarding inputs, detailed left/right haptics and adaptive-trigger effects. Phantom Blade Zero on Steam is the initial validation target.

- Includes haptic-buffer and USB/IP scheduling improvements, bounded background diagnostics, feedback tests and a USB/Bluetooth comparison panel.
- No automatic startup. A normal stop restores this session's HID hiding changes and removes its virtual device. Exit the game before switching modes.
- Chinese and English documentation, project artwork, MIT license and third-party notices included. The application UI is currently Chinese.

Download and fully extract `DualSense-AirBridge-v0.1.4-win-x64.zip`, then run `DualSenseBridge.exe`. The .NET 9 runtime is bundled; install the official **usbip-win2 0.9.8.1** and **HidHide 1.5.230.0** drivers separately using the links above. Follow any restart prompt. See the [English README](https://github.com/stayupchampion/DualSense-AirBridge/blob/v0.1.4/README.en.md).

`SHA256SUMS.txt` provides checksums; `build-manifest.json` identifies the source commit and binaries. GitHub's automatic source archives are not runnable distributions. The executable does not have a commercial code-signing signature.

The release workflow rebuilds the source and runs 121 C# checks, native runtime/diagnostic checks, 3 patch checks and driver-free lifecycle tests. Prior manual testing covered haptics, R2 resistance, cancellation, normal restoration and independent Bose Bluetooth audio. CI does not test physical controllers.

Reported vibration feel is close to USB on the tested setup; physical latency equivalence has not been measured. The controller speaker produced no sound; microphone and 3.5mm audio remain unverified. Edge, DS4 and Xbox bridging are unsupported. Broader game compatibility and concurrent controllers still need validation.

The backend derives from [vDS](https://github.com/hurryman2212/vds), with usbip-win2, HidHide and Opus dependencies. Full upstream credits, pins and research references are in the READMEs. Project code is MIT; third-party licenses remain intact.
