# 界面与交互改版

> 历史开发记录；对应功能已随 [v0.1.5](releases/v0.1.5.md) 发布，当前验收见 [软件验证记录](validation.md)。

本轮按“参考苹果界面的简洁风格，只改界面、不改核心功能”的要求完成。使用现有 WinForms 框架，不引入 WebView、浏览器运行时或新依赖，不替换 Windows 原生标题栏。

## 主要变化

- 连接概览：主操作、实际会话状态和实体连接放在同一区域；电量与声音独立分组。桥接运行时显示停止并恢复原生的操作。
- 检查与恢复：环境信息、会话记录、导出和遗留状态恢复集中呈现。打开指南不会覆盖环境检查结果；导出后直接展示保存路径所在的检查页面。
- 使用指南：作为独立页面保留，随时切换回来，不改变当前桥接。
- 反馈测试：按精细触觉、扳机和扬声器分组，展示预计时长；“立即停止”和当前测试状态始终放在记录区域顶部。静音选项仍适用于扬声器测试。
- 延迟对比：目标、项目及拍摄帧率分别标注。原有高对比画布、绘制时间戳和采集节奏保持不变，以免界面改版改变对照方法。
- 键盘和读屏：保留原生按钮与复选框语义，提供焦点标记、控件名称和实时文本；主窗口支持缩小后滚动查看内容。

## 核心边界

新的 `UiTheme.cs` 和各 `*.Layout.cs` 只负责布局、字体、配色与绘制。会话启动、停止、取消、异常清理、设备读取、音频保护、反馈信号、后端补丁及驱动不在本轮修改范围内。电量和音量的刷新频率不变，没有加入动画计时器或新的后台任务。

本轮基于本地已有的 `0.1.5-dev` 候选代码，界面预览不表示此前自然待机、Bose 音量或新增静音功能已经通过实机验收；这些问题的验证边界保持原记录。
