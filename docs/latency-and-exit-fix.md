- 管理层将配置清理结果与手柄/音频观测拆开，并保存恢复诊断。观察窗口不代表之后永不掉线。

## 当前边界

虚拟 USB 消失、真实蓝牙 HID 重新可见，是两个不同设备的切换；无法承诺已运行的游戏自动重绑，也无法让原生蓝牙继承虚拟 USB 的功能。游戏内切换后若识别异常，应退出并重新启动游戏，不通过强制重置蓝牙来修复。

现有证据确认耳机端点后来断开，但尚不足以确定是手柄残留输出、Windows 蓝牙栈、Steam 或其他因素造成。最终输出清理是确定的实现缺口修复，不能据此宣布耳机根因已解决。

软件缓冲数值不是按键延迟或手感端到端测量。硬件记录见下文。
